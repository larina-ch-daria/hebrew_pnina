# Мора Пнина — иврит для первых недель

Ежедневная игра: сцены из жизни после переезда, около ста фраз, слов и вывесок за 14 дней.
Учительница-черепаха ругается на иврите за ошибки, а ругательства собираются в коллекцию.

Из одного репозитория получаются две версии:

- **PWA** — сайт на GitHub Pages, который ставится на телефон как приложение. Работает на Android и iPhone, офлайн тоже.
- **APK** — установочный файл для Android. Собирается автоматически и появляется в Releases.

## Первый запуск

1. Создай на GitHub пустой репозиторий. Для бесплатного GitHub Pages он должен быть публичным.
2. Залей файлы через git. При перетаскивании в браузер скрытая папка `.github` может не загрузиться.

   ```bash
   git init
   git add .
   git commit -m "Мора Пнина"
   git branch -M main
   git remote add origin https://github.com/ИМЯ/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
   Если первый запуск «PWA на GitHub Pages» упал до этой настройки, перезапусти его во вкладке Actions.
4. Во вкладке **Actions** должны пройти два процесса: «PWA на GitHub Pages» (около минуты) и «APK» (5–10 минут).

## Как поставить

**PWA.** Открой `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/` на телефоне.
- Android, Chrome: меню → «Установить приложение» (или «Добавить на главный экран»).
- iPhone, Safari: «Поделиться» → «На экран „Домой“».

**APK.** На телефоне открой страницу репозитория → **Releases** → последняя сборка → `mora-pnina.apk`.
Android попросит разрешить установку из этого источника. Play Защита может предупредить, что приложение неизвестное: это нормально для сборки не из магазина.

## Озвучка

Нужен голос для иврита в системе. Пункты меню у разных производителей называются по-разному, но примерно так:
- Android: Настройки → Специальные возможности → Синтез речи → настройки «Синтеза речи Google» → Установка голосовых данных → иврит.
- iPhone: Настройки → Универсальный доступ → Устный контент → Голоса → иврит.

## Перенос прогресса

Прогресс хранится на устройстве. Чтобы перенести его (из браузера в APK, между телефонами), открой экран «Кто учится?» (кнопка с именем в шапке) → «Перенос прогресса»: на старом устройстве скопируй код, на новом вставь.

## Как обновлять

1. Правь `www/index.html` — в нём всё приложение: сцены, фразы, вывески, движок.
2. **Увеличь номер версии** в `www/sw.js` (`pnina-v1` → `pnina-v2`). Без этого PWA на телефонах продолжит показывать старую версию.
3. `git push` — оба процесса пересоберутся сами. Новый APK ставится поверх старого: ключ подписи постоянный (`keystore/debug.keystore`), прогресс не теряется.

## Что где

```
www/                 приложение (это и есть PWA)
  index.html         всё приложение в одном файле
  sw.js              офлайн-кэш, номер версии
  manifest.webmanifest
  fonts/             Rubik, Frank Ruhl Libre, Playpen Sans Hebrew (OFL)
  icons/
assets/              исходники иконки и заставки для APK
keystore/            отладочный ключ подписи APK — не секретный, нужен для обновлений поверх
capacitor.config.json
.github/workflows/   pages.yml — PWA, apk.yml — APK
```

Собрать APK у себя (нужны Node 22, JDK 21 и Android SDK):

```bash
npm install
npx cap add android
npx @capacitor/assets generate --android
npx cap sync android
cd android && ./gradlew assembleDebug
```
